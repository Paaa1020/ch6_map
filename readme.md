# 🚇 부산 지하철 역별 이용객 수 지도 분석 앱

파이썬 초보 비전공자 학생이 Streamlit과 Folium을 활용하여 만든 부산 지하철 데이터 시각화 웹 애플리케이션입니다. CSV 파일을 업로드하여 부산 지하철 역별 이용객 수를 직관적인 지도와 표로 확인할 수 있습니다.

---

## ✨ 주요 기능

1. **CSV 데이터 업로드 및 미리보기**: `busan_subway.csv` 파일을 업로드하면 전체 데이터를 표 형태로 확인할 수 있습니다.
2. **이용객 상위 5개 역 시각화**: 전체 데이터 중 이용객 수가 가장 많은 상위 5개 역을 표로 따로 보여줍니다.
3. **호선별 멀티셀렉트 필터**: 원하는 호선만 골라서 지도에 표시할 수 있습니다.
4. **호선별 맞춤 색상 및 크기 원형 마커**:
   - **1호선**: 주황색 (`orange`)
   - **2호선**: 초록색 (`green`)
   - **3호선**: 갈색 (`brown`)
   - **4호선**: 파랑색 (`blue`)
   - 마커의 반지름은 이용객 수의 **제곱근(Square Root)**에 비례하도록 설정하여 면적이 이용객 수를 정확히 반영하도록 구현했습니다.
5. **인터랙티브 툴팁 & 팝업**: 
   - 마우스를 올리면 호선과 역 이름이 나타납니다.
   - 마우스를 클릭하면 정확한 이용객 수를 확인할 수 있습니다.

---

## 🛠️ 기술 스택 (Tech Stack)

- **Python**
- **Streamlit** (웹 어플리케이션 프레임워크)
- **Pandas** (데이터 전처리 및 분석)
- **Folium & Streamlit-Folium** (인터랙티브 지도 시각화)

---

## 🚀 실행 방법 (Getting Started)

1. 이 저장소를 클론하거나 코드를 다운로드합니다.
2. 터미널에서 프로젝트 폴더로 이동한 뒤, 필요한 라이브러리를 설치합니다.
   ```bash
   pip install -r requirements.txt
   ```
3. 아래 명령어를 실행하여 Streamlit 앱을 엽니다.
   ```bash
   streamlit run app.py
   ```
4. 브라우저가 열리면 `busan_subway.csv` 파일을 업로드하여 결과를 확인하세요!
